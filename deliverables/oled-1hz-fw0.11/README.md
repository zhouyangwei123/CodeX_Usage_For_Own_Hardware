# App0.11：1Hz用量页试验固件

[下载Application-0.11.bin](Application-0.11.bin)。本机已通过USB升级并回读验证；本机波形页和账号额度页每秒最多更新一次，相同画面跳过写屏。实际噪音改善待用户听感反馈，完整检查见[试验记录](../../docs/OLED_1HZ-20261023.md)。

使用Host0.6.2“诊断与设置 → 设备固件升级”，选择这个BIN。设备需已安装Boot1.0并具备USB升级入口；仅更新应用，不重新安装或解除启动区保护。上位机EXE与配置保持。原App0.10包保留在[此前交付](../usb-update-0.6.1/README.md)，可用于对比或回退。

`SHA256SUMS.txt`用于核对固件字节；不要把BIN当作上位机程序运行。此试验未替换正式Host0.6.2发布包。
