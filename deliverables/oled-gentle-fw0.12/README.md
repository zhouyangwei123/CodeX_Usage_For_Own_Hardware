# App0.12：温和三档随机时钟

[下载Application-0.12.bin](Application-0.12.bin)。正常用量页恢复此前温和三档内部时钟扰动，同时保留1Hz内容更新与相同画面跳过写屏。本机已通过USB更新并回读校验，用户确认“显示正常，噪音有所减轻”。参数和实测边界见[试验记录](../../docs/OLED_GENTLE-20261026.md)。

使用Host0.6.2“诊断与设置 → 设备固件升级”选择此BIN；设备需已具备Boot1.0及USB升级入口，只更新应用。上位机和配置沿用，正式Release保持。本固件按SSD1306路径验证，显式SH1106不启用这组时钟扰动。

SHA256SUMS.txt核对固件字节。可用[App0.11](../oled-1hz-fw0.11/README.md)返回固定内部时钟、1Hz写屏版本作对比。
