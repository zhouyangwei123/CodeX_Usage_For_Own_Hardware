# USB 串口稳定性候选版

分支：`fix/usb-serial-stability`。上位机 **0.4.3**，固件 **0.8**。**已完成离线回归和构建，待烧录及真实硬件验收。**

- [下载完整修复包](NewMarTool-serial-stability-FW0.8-Host0.4.3.zip)：含上位机、HEX/BIN/ELF、源码补丁、使用说明与测试结果。
- [下载可烧录 HEX](NewMarTool-FW-0.8.hex)：目标 STM32G474RBTx，Flash 地址 0x08000000。
- [校验值](SHA256.txt)。
- [详细修改与验证记录](../../docs/USB_STABILITY-20261022.md)。

接上 ST-Link 后，先识别实际芯片、读取当前 Flash 备份，再写入 HEX、校验并复位。确认设备上报 FW 0.8 后，按验证记录进行持续运行、睡眠/唤醒及重连测试。没有执行过本次实机烧录，不应把离线测试结果当作长期实机验收。

修复针对协议层重复维护发送忙标志引起的回调竞态和断连后无法恢复；同时修正忙时丢帧、未配置 USB 访问和接收长度越界，上位机自动扫描跳过蓝牙虚拟串口并补充握手错误提示。通信协议兼容原上位机0.4.2。

用户目前未携带 ST-Link，因此保留可烧录候选版本，后续继续实机验证。
