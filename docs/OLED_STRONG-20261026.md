# App0.13：五档随机时钟对比

用户确认[App0.12温和三档](OLED_GENTLE-20261026.md)显示正常、噪音有所减轻后，要求再测试此前五档模式。App0.13恢复旧round-5 strong试验的五档范围与节奏，日常用量页仍最多每秒更新一次，相同画面跳过写屏。

| --- | --- | --- |
| D5控制值 | 0x90 / 0xA0 / 0xB0 | 0x80 / 0x90 / 0xA0 / 0xB0 / 0xC0 |

两者均使用原7位LFSR、0x5D种子及相同递推；分频低四位为0，亮度、预充电、I2C总线速率和上位机保持。D5值是内部时钟配置，不是测量所得的Hz；5ms步进所得间隔也不是示波器测量。正常页面保持可用，不启动旧诊断的自动扫档或画面冻结。

完整生产OLED驱动在HAL边界检查：10秒5ms步进内发出666次时钟命令，五档均出现，没有画面数据写入。占用中的DMA/I2C不插入命令，HAL_BUSY后恢复、11ms门槛、32位计时回绕、失败后重新初始化及显式SH1106排除检查通过。此前12种1Hz页面/状态调度、画面去重、DMA与阻塞降级检查继续通过。镜像9项、升级请求3项、更新器55项、PowerShell5.1中文路径检查通过。

ARM构建0错误0警告；封装应用47,840/57,344字节，data+bss为14,732字节，Boot1.0封装字节与0.12相同。

本机已通过USB从App0.12更新到0.13，独立回读逐字节一致，完整8KiB启动区与44字节选项保持。错误DFU身份在内存操作前被拒绝，实际写入期间托盘退出保护生效。生产真实数据与SerialLink连续60.233秒内234/234次带标记回显匹配，未回答0、意外回显0、错误ACK0；本机与账号各40帧，来源切换、历史曲线、输入输出合计、PC28字节及OLED在线检查通过，之后恢复Host0.6.2日常显示。见[结构化证据](evidence/oled-strong-20261026.json)。
