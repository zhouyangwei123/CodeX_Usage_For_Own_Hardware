## ccusage 接入

ccusage 的 Codex 支持读取本机 `sessions/` 和 `archived_sessions/` JSONL，提供日、月和会话视图以及 JSON 输出。其 Codex 日志支持仍标为实验性；必须锁定版本、保留去重样本与对账结果。

建议分两层接入：

1. 先做一个可选导入/对账适配器，运行固定版本的 `ccusage codex daily --json --offline` 或 session 报告。只在用户刷新、启动或低频后台触发时运行，不每秒全量扫描。
2. 近实时会话数据使用上位机内的 C# 增量读取器，保存文件偏移、会话及分叉基线，读取新增 token_count。用第一层报告对照选定时间段，验证无重复累计。

ccusage 当前主体是统计 CLI/数据源，不应把网站的展示样式当作可直接嵌入的桌面控件。新版界面可以使用它的结构化结果，按用户偏好重新呈现。

用量列表建议列：时间/会话、模型、输入、缓存输入、输出、总量、估算费用、最近更新。提供今日/7天/本月/会话切换及 CSV 导出。缓存输入属于输入的子集；推理量不重复加到已含推理的输出量中。缺失模型价格显示未知。

账户历史统计来自 `account/usage/read`，本机会话统计来自本地记录；两者独立展示、不相加。API 等价费用与订阅额度百分比也不混为一谈。

参考：https://ccusage.com/guide/codex/

## 玻璃质感方案

优先保持 WinForms/单 EXE，做柔和分层底色、半透明感的内容卡片、细分隔线和清晰数值表格。对于浮窗，预留“标准/玻璃”两种风格；常规设置页面保留高可读性。

若需要真实背景材质，可评估 Windows DWM 系统背景接口（Mica/Desktop Acrylic）。该能力有 Windows 版本要求，且 WinForms 背景、透明区域、远程桌面与高对比度行为需要实测；不支持时自动回退为不透明主题。第一步先做对照样稿与一个小型兼容性验证，不整体迁移 UI 框架。

备选为专门的 WebView2 报表页面，可以更容易实现复杂表格和 CSS 玻璃效果，但会增加运行时和常驻资源依赖。只有原生方案无法达到确认效果时再选择。

微软依据：https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type
