# CodeX Tools Host 0.6.3

上位机现在显示本机全部会话的合计输出速率，并修复短暂额度刷新失败时数字消失的问题。

## 本次更新

- 默认统计本机全部会话，各会话分别平滑、并行相加，全部结束后当前速率归零。
- 底栏直接显示`123/s`；最近一小时曲线继续表示分钟用量，保留输入、输出分项和历史补画。
- 同一账号短暂刷新失败时保留最近成功的额度、倒计时和进度条；退出登录或切换账号时清空。
- 保留像素皮肤和本机用量默认设置，可手动切换账号日汇总；移除新增的速率前缀及纵轴旁小标记。

## 更新方法

1. 下载本页附件`CodexToolsHost-0.6.3.zip`。
2. 退出旧上位机，将包内`CodexToolsHost.exe`覆盖原安装目录的EXE，再启动。
3. 保留原`CodexToolsHost.json`，原有配置继续使用。0.4.2、0.6.2可通过“软件更新 → 立即检查”发现本版，下载与安装需手动完成。

安装包只含上位机单EXE，不含个人配置、日志或认证信息，不需要Python，不更新设备固件；实体OLED保持现有显示。
