# 0.4.0：可折叠 Token 活动曲线

额度浮窗底部固定为 **API / TOKEN / NET** 三列。TOKEN 的 `↑入` 是输入 Token，`↓出` 是输出 Token，单位为每分钟；NET 仍是网络流量每秒。Token 并不是网卡字节数，也不等同于订阅额度百分比。

点击“近 1 小时”右侧的小箭头可隐藏或展开曲线，底部输入/输出数值始终保留。也可右击托盘选择“显示 Token 曲线”。状态会保存，下次启动沿用；新配置默认展开。折叠保持右下角位置，接近屏幕边缘时在当前屏幕内调整。

## 数值含义

- 曲线每 10 秒增加一个点，保留最近一小时，最多 361 个端点。每个点代表截至那个时刻最近 60 秒内的输入加输出。
- 底部输入/输出分别统计采样时刻最近 60 秒的本机已上报用量，另显示最近一小时总量。
- 输入包含缓存，输出包含推理；这些子项不重复相加。首次扫描按记录原始时间归位，不把刚读到的历史算成当前消耗。
- 原生扫描器对累计重复、活动/归档副本及分叉继承处理后，才提供时间序列。ccusage 的日/月导入报告不参与实时曲线。
- 这是记录回报速率，不是精确模型生成速度。上游批量回报会让曲线有起伏，持续无新记录也不证明模型已经停止。

## 数据状态

- **正常 / 无新记录**：扫描工作正常，最近 60 秒没有新增记录时输入、输出为 0。
- **扫描中**：历史仍在分段加载，显示未知值，不绘制完整曲线。
- **部分记录**：数据覆盖不完整，只展示已采纳的记录，数字加 `≥` 提示并保留覆盖状态；详细原因在用量清单查看。
- **数据过期 / 读取失败 / 不可用**：不显示为真实零，也不把旧数据继续画成新曲线。最近一次成功扫描超过 30 秒即视为过期；该判断与任务是否空闲无关。

鼠标停留在底部可查看完整 API 摘要、Token 原始整数及最近记录时间。小尺寸下 API 使用简写和省略号，完整信息仍在悬停提示与设置页中。输入/输出始终保留在底部，隐藏曲线不会关闭后台采集。

## 效率与范围

沿用已有本机读取服务，不增加官方额度接口轮询。已知日志每 5 秒检查，新会话发现周期仍为 60 秒，因此刚创建的任务可能延迟约一分钟纳入。每次磁盘扫描最多 32 MiB；活动序列最多保留 3,670 秒、50,000 个数值事件，超过上限明确标为部分记录。

HUD 最多每个 10 秒时间桶投影一次；显示时使用轻量计时器让过期记录自然移出窗口，隐藏时停止视图计时器。共享采集服务继续供用量清单和再次显示使用。曲线没有持续装饰动画。

浮窗继续使用 WinForms 原生逐像素透明合成，保留柔光玻璃、极简清晰、经典双色和不透明回退。玻璃不是实时背景模糊/折射。固件、串口协议和设备显示均未修改。

配置升级为版本 11，新增布尔字段 `quotaHudChartExpanded`；旧字段、绑定、密钥及更新检查偏好保留。
