# Token用量与可折叠活动曲线

Host0.6.3在本机模式接入全部本机会话的近似输出速率：各会话分别测速和平滑，并行相加；轮次完成或停止即移除，全部结束为0。普通皮肤中列及像素皮肤底栏主数字显示`123/s`。曲线仍为Token/分钟，底栏箭头仍是最近60秒输入、输出量。账号模式仍为日汇总。算法、验证和设备范围见[本机速率接入记录](TOKEN_RATE_HOST-20261028.md)。

Host0.6.2修复Codex分页日志被误判为重复副本、导致近期曲线为空的问题。启动时自动读取日志，按原始时间补回最近一小时；后续分页、重叠页和归档副本去重后继续累计。纵轴为Token/分钟，采用整档自动缩放；整小时都为零时最小量程为0、0.5、1，并非测试数据。详见[历史曲线修复记录](USAGE_HISTORY-20261023.md)。

0.6.1默认本机，托盘“用量来源”或设置“用量清单”可手动切换账号日汇总并保存，所有皮肤同步选择。账号模式显示累计、最近统计日期、Token/日与查询时间；清单仅显示服务端已返回日期。账号汇总可能延迟，没有逐秒Token速率，也没有输入/输出分项。详见[最新验收与说明](USB_OLED-20261023.md)。

普通皮肤底部为 **API / 输出 / NET** 三列；像素OLED皮肤保留一行底栏、35像素曲线。以下分钟活动口径仅适用于切换到本机后：`↑` 是输入Token，`↓` 是输出Token；NET始终为网络流量每秒。Token不是网卡字节，也不等同于订阅额度百分比。

点击曲线右侧小箭头可隐藏或展开曲线，底部数值保留；像素皮肤点击底栏折叠。也可右击托盘选择“显示 Token 曲线”。状态保存，下次启动沿用；新配置默认展开。折叠保持右下角位置，接近屏幕边缘时在当前屏幕内调整。

## 本机数值含义

- 曲线每 10 秒增加一个点，保留最近一小时，最多 361 个端点。每个点代表截至那个时刻最近 60 秒内的输入加输出。
- 底部输入/输出分别统计采样时刻最近 60 秒的本机已上报用量，另显示最近一小时总量。
- 输入包含缓存，输出包含推理；这些子项不重复相加。首次扫描按记录原始时间归位，不把刚读到的历史算成当前消耗。
- 原生扫描器对累计重复、活动/归档副本及分叉继承处理后，才提供时间序列。ccusage 的日/月导入报告不参与实时曲线。
- 这是记录回报速率，不是精确模型生成速度。上游批量回报会让曲线有起伏，持续无新记录也不证明模型已经停止。

## 数据状态

- **正常 / 无新记录**：扫描工作正常，最近 60 秒没有新增记录时输入、输出为 0。
- **扫描中**：历史仍在分段加载，显示未知值，不绘制完整曲线。
- **部分记录**：数据覆盖不完整，只展示已采纳的记录，数字加 `≥` 提示并保留覆盖状态；详细原因在用量清单查看。
- **数据过期 / 读取失败 / 不可用**：不显示为真实零，也不把旧数据继续画成新曲线。最近一次成功扫描超过 30 秒即视为过期；该判断与任务是否空闲无关。

0.5.1起已移除鼠标悬停提示；完整数值在设置中查看。本机输入/输出保留在底部，隐藏曲线不会关闭后台采集。

## 效率与范围

本机模式沿用已有读取服务。Host0.6.3起已知日志每0.5秒检查，新会话、分页与归档每3秒发现；不另启动Python进程。每次磁盘扫描最多32MiB；活动序列最多保留3,670秒、50,000个数值事件，超过上限明确标为部分记录。账号汇总复用现有Codex连接，每5分钟查询，手动刷新可立即请求；15分钟未成功查询标为过期。账号读取失败不切换到本机。

HUD最多每秒更新一次，曲线仍每10秒一个点；显示时使用轻量计时器让过期记录自然移出窗口，隐藏时停止视图计时器。共享采集服务继续供用量清单和再次显示使用。速率随响应完成更新，不代表取得了逐Token流。曲线没有持续装饰动画。

浮窗使用WinForms原生逐像素透明合成，保留柔光玻璃、极简清晰、经典双色，新增像素OLED。像素皮肤保留128×64内容，外加4逻辑像素马赛克边框；默认75%为408×216，内容仍为整数3倍。顶部文字在设备第2行起绘制，曲线仍为35像素。App0.10以新增独立消息接收账号/本机曲线，STATUS和PC_METRICS长度保持。

配置版本仍为11；`quotaHudChartExpanded`控制折叠，`usageDisplayScope`为account/local且缺省local，显式account仍会保留；`quotaHudStyle=pixel`选择像素皮肤。新配置默认OLED页4（本机），AUTO在本机与PC之间轮播；账号页仍可手动选择。旧绑定、密钥及更新检查偏好保留。
