# 剩余额度间断显示

截图中的`7D -- --`来自上位机显示层：`CodexStatusProvider`在短暂请求失败或断开时保留最近成功的额度，标记`IsStale`；像素皮肤要求`QuotaKnown && !QuotaStale`才显示百分比、倒计时和填充条，因此原值仍在却被隐藏。带活动曲线的普通皮肤也使用了同样的隐藏条件。

本轮只修改主机显示：有最近成功值时继续显示，后台失败状态与原观察时间保持；账号退出、账号变化或从未取得数值时仍为空。无需新增缓存文件或第二个读取来源。实体OLED保持原协议行为及固件，不把主机显示修复改写成设备固件验收。

在本机对实际Codex app-server观察150秒，首次`account/read`耗时约14.47秒，并收到一次未退出登录的`account/updated`；约16.12秒取得首笔7D额度。其后额度刷新均成功，未观察到重连或已成功后反复失去数值。因此已确认“过期标志会隐藏已有额度”的代码问题及启动等待，尚不能将用户每次中断都归因于某个已抓到的网络错误。此前几次本机版本替换均重启了上位机，启动时需要重新读取额度。

134项原生主机检查通过：新增两种来源视图的失败保值、帧不被修改、已清空账号不恢复旧数值，以及玻璃/极简/经典皮肤的百分比与填充区域比较。25组额度可靠性检查通过，包含未登录、身份变化、迟到推送与读取失败；HUD77项、账号/OLED/皮肤203项、26组C/C#完整帧比较及216种Demo栅格状态通过。记录只保留时序、成功/失败与字段可用性，不导出账号标识或个人额度数值。
