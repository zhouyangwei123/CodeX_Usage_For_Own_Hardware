# CodeX Tools Host 0.6.2

本次正式发布将已测试的Host0.6.2安装包接入现有GitHub更新渠道。0.4.2及后续版本查询仓库的`releases/latest`；正式版本需创建非草稿、非预发布Release并设为最新，推送分支不会自动发布。代码取自`feat/account-oled-pixel-20261023`，无需合并main即可由标签固定发布。

## 从0.4.2更新

1. 打开“诊断与设置 → 软件更新”，点击“立即检查”，应发现`v0.6.2`，再点击“打开GitHub发布页”。
2. 下载`CodexToolsHost-0.6.2.zip`；这是上位机单文件包，不包含个人配置与设备固件。
3. 退出旧程序，把解压后的`CodexToolsHost.exe`覆盖原安装目录中的EXE，再启动。保留原`CodexToolsHost.json`；用户本地应用数据中的配置也继续使用。建议保留旧EXE供回退。
4. 下载与安装需手动完成，程序不会自动替换自身或烧录设备。新配置默认像素皮肤、固定本机波形页；旧配置中已选择的外观、显示选项、绑定、串口及密钥保留。已有用户如需像素皮肤，可在“显示与灯效”或托盘外观菜单切换。

## 相对0.4.2的主要变化

- 修复Codex分页日志被误认作重复副本导致近期用量遗漏的问题；启动按原时间补回最近一小时。纵轴为Token/分钟，自动按整档缩放；整小时为零时最低刻度0、0.5、1属正常情况。
- 增加与设备相同的像素OLED皮肤，顶部留白、马赛克边框、一行底栏与35像素曲线；移除鼠标悬停信息窗。
- 本机用量保持默认，可手动切换整账号日汇总。服务端日汇总有延迟，不能当作逐秒生成速率；本机底栏是最近60秒已上报用量。
- 带入串口稳定性、USB升级安全检查和OLED波形支持；设备App0.10默认本机波形页、不自动轮播。

## 设备固件

已安装App0.10的设备仅需更新本次EXE。旧设备的基本连接路径继续保留，但新OLED波形页需要App0.10；上位机更新不会把旧固件自动变成0.10。USB升级需设备已具备Boot1.0及升级入口，旧设备首次安装仍需ST-Link。具体固件包、驱动与安装范围见[USB与OLED说明](USB_OLED-20261023.md)，勿把上位机ZIP用作设备固件。

## 已验证与边界

Host0.6.2的本机活动30组、原用量26组、HUD77项、账号/OLED/皮肤203项、26组完整帧比较及216种Demo栅格组合通过；内置自检86项、模拟4项通过。真实本机日志首次扫描可恢复过去曲线，生产链路实际向App0.10发送非零曲线。个人Token数值、配置与认证均未纳入包。
