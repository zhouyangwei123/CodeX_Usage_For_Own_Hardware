# CodeX Tools 0.4.0：先看这里

这是 Windows 托盘上位机与 STM32G474 固件的联合工程。固件当前仅原样纳入版本管理。

## 使用

运行发布程序 `CodexToolsHost.exe`，右击托盘图标选择“打开设置”。程序采用单实例运行；重复双击不会再创建一个托盘实例。

配置界面有六项导航：总览、按键与旋钮、显示与灯效、服务与集成、诊断与设置、用量清单。没有设备时，Codex 额度、API 余额、电脑监控和本机 Token 统计仍可独立工作，“设备未连接”不代表额度请求失败。

在“显示与灯效 → 桌面额度浮窗”选择柔光玻璃、极简清晰或经典双色，预览后点击“应用浮窗外观”；也可右击托盘直接切换。新版圆角使用平滑透明边缘。柔光玻璃提供半透明层次与高光，不包含桌面实时模糊或折射；高对比度或原生合成失败时回退为不透明显示。

Codex 额度需要这台电脑的 Codex 登录状态。窗口名称按接口提供的时长显示，只有一个窗口时，第二窗口无数据是合法情况。短暂请求失败会保留上一次成功值，并标记陈旧与采样时间。

浮窗底部三列为 API、TOKEN、NET。TOKEN 的 `↑入 / ↓出` 是最近 60 秒的输入/输出 Token，每分钟显示；NET 仍是网络流量每秒。点击一小时摘要右侧的小箭头可折叠曲线，Token 数字继续显示，状态下次启动沿用。曲线每 10 秒更新，覆盖最近一小时；悬停底部可看完整摘要。“部分记录”表示已读范围不完整，“无新记录”表示没有新用量回报，均不等于模型真实瞬时生成速度。

DeepSeek API 余额查询保留；旧的 Codex 账号切换功能已移除。如果旧配置把按键或旋钮绑定到该切换动作，新版会停用对应绑定并在设置中提示。

## 配置文件

新发布目录只需 EXE。默认配置在 `%LOCALAPPDATA%\CodexToolsHost\CodexToolsHost.json`；如果旧程序目录已有同名配置，则继续兼容该位置。

保存采用临时文件与原子替换，上一版配置保留为同目录 `.bak` 文件。发布包和 Git 不包含真实配置、API Key、Codex 认证文件或米家登录资料。

## 构建与验证

运行 `host/build.ps1`，输出在 `host/release/CodexToolsHost.exe`。构建依赖 Windows 的 .NET Framework 4.8 编译器，依赖库在构建时嵌入 EXE。

开发者验证命令和当前验收边界见 `CODEX_接手说明.md`。固件完整性可运行 `tools/verify-firmware.ps1`；152 个文件应全部匹配导入校验清单。

## 当前边界

用量清单默认读取本机 Codex 日志，首次读取分段进行并标明进度；已知文件每 5 秒增量刷新，新会话最多约 1 分钟后发现。本机记录可能缺失或不完整，查看覆盖提示；这些数值不是订阅扣费或全账户账单。ccusage 导入帮助位于用量页，应用不会安装或执行 npm。

“诊断与设置 → 软件更新”可立即检查或关闭自动检查。公开仓库无需 GitHub 登录；新版本会显示在托盘菜单，只有主动点击才打开发布页，程序不会自动替换自己。

当前固件的 OLED、RGB 和按键行为没有修改；实机联调待设备在手时进行。真实多屏 DPI、系统睡眠/恢复与长期 Token 扫描仍有单独验收边界，详见仓库验证记录。
