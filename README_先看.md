# CodeX Tools 0.2.0：先看这里

这是 Windows 托盘上位机与 STM32G474 固件的联合工程。固件当前仅原样纳入版本管理。

## 使用

运行发布程序 `CodexToolsHost.exe`，右击托盘图标选择“打开设置”。程序采用单实例运行；重复双击不会再创建一个托盘实例。

配置界面有五项导航：总览、按键与旋钮、显示与灯效、服务与集成、诊断与设置。没有设备时，Codex 额度、API 余额和电脑监控仍可独立工作，“设备未连接”不代表额度请求失败。

Codex 额度需要这台电脑的 Codex 登录状态。窗口名称按接口提供的时长显示，只有一个窗口时，第二窗口无数据是合法情况。短暂请求失败会保留上一次成功值，并标记陈旧与采样时间。

DeepSeek API 余额查询保留；旧的 Codex 账号切换功能已移除。如果旧配置把按键或旋钮绑定到该切换动作，新版会停用对应绑定并在设置中提示。

## 配置文件

新发布目录只需 EXE。默认配置在 `%LOCALAPPDATA%\CodexToolsHost\CodexToolsHost.json`；如果旧程序目录已有同名配置，则继续兼容该位置。

保存采用临时文件与原子替换，上一版配置保留为同目录 `.bak` 文件。发布包和 Git 不包含真实配置、API Key、Codex 认证文件或米家登录资料。

## 构建与验证

运行 `host/build.ps1`，输出在 `host/release/CodexToolsHost.exe`。构建依赖 Windows 的 .NET Framework 4.8 编译器，依赖库在构建时嵌入 EXE。

开发者验证命令和当前验收边界见 `CODEX_接手说明.md`。固件完整性可运行 `tools/verify-firmware.ps1`；152 个文件应全部匹配导入校验清单。

## 当前边界

本版新增的是上位机稳定性和界面整理。Token 清单、玻璃风格浮窗与 GitHub 自动更新检查仍属于下一阶段，尚未接入。当前固件的 OLED、RGB 和按键行为没有修改；实机联调待设备在手时进行。
